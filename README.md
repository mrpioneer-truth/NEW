# NEW방 ONLINE

『NEW방: 아직 아무도 나가지 않았다』의 액션판. 텍스트 퍼즐을 걷어내고 **FPS·TPS 슈팅 + MMORPG식 파티·성장**으로 바꿨습니다. 화면은 저해상도 DSLR 뷰파인더(● REC, ISO·셔터·조리개, 배터리, AF 포인트, 센서 노이즈, 색수차)로 보입니다.

- 전체 용량 **약 0.9 MB, 파일 21개**. 외부 라이브러리·CDN·빌드 없음.
- 인물·방·사건·결말 문장은 이전 판의 `data.js`를 그대로 씁니다.

## 실행

- **로컬**: 폴더째로 두고 `index.html`을 Chrome·Edge·Safari에서 엽니다.
- **GitHub Pages**: 이 폴더 내용을 저장소 루트에 올리고 Settings → Pages에서 브랜치를 지정하면 끝. `.nojekyll` 포함.

조준 보조가 있어 십자선 근처의 적은 맞습니다. 죽어도 3초 뒤 마지막으로 복원한 방에서 다시 시작하고, 잃는 것은 없습니다.

## 흐름

1. 여섯 명 중 한 명을 고르면 나머지 다섯 명이 **AI 파티원**으로 따라옵니다 (이름표·체력바·파티 채팅·다운/부활).
2. 방에 들어가면 잡음·반향·왜곡체가 나옵니다. 다 쓰러뜨리면 방 가운데 **봉인**이 생기고, 먹으면 그 방의 기억 한 줄이 뜹니다.
3. 경험치로 레벨업, 적이 떨어뜨리는 무기는 **일반·희귀·영웅·전설** 등급이고 더 좋으면 자동 장착, 아니면 분해해 경험치로.
4. 봉인 **12개**를 모으면 가장 남쪽 방의 출구가 열리고 보스 **방문자**가 나옵니다. 쓰러뜨리면 결말.

## 예측 불가 요소

- **건물 규칙 변경** (30–50초마다 18초간): 저중력 · 정전 · 거울 세계 · ISO 25600(화질 붕괴, 경험치 2배) · 잡음 폭주 · 보급 낙하 · 셔터 1/8000 · 거인 시점 · 방 섞기(파티 전체 순간이동) · 접속자 7 / 6(아군 또는 적으로 접속) · 플래시 과충전(폭발탄) · 연사 모드
- **선택 사건**: data.js의 사건 12종이 1분 남짓마다 카드로 뜹니다. 고른 쪽에 따라 자유(피해↑)·명료(치명타↑)·연결(파티 회복·부활)이 쌓이고 결말이 갈립니다. 일부는 방문자 형상이 잠깐 나타납니다.
- 맵은 매번 새로 섞입니다. 방 배치·색·엄폐물·적 구성이 달라지고, 숨은 방 「접속자 7의 방」이 어딘가에 있습니다.
- 보스는 체력이 절반이 되면 규칙을 강제로 바꿉니다.

## 결말 6종

| 결말 | 조건 (위에서부터 우선) |
|---|---|
| 02 최종본_진짜최종 | 「접속자 7의 방」 봉인에서 출구 설계도 획득 |
| 06 건물 밖에 쓰는 말 | 자유 7 이상 |
| 03 읽음 표시 없는 밤 | 명료 6 이상 |
| 05 여섯 개의 빈칸 | 연결 6 이상 |
| 04 남기로 한 사람 | 방 15개 이상 복원 |
| 01 열어 둔 문 | 그 밖의 모든 경우 |

발견한 결말과 최고 레벨만 브라우저 localStorage(`newroom-online-v1`)에 저장됩니다. 한 판은 20–30분을 목표로 했고, 진행 중 저장은 없습니다.

## 구성

```
index.html, style.css
js/engine.js       저해상도 WebGL 렌더러 + DSLR 후처리 셰이더
js/world.js        5×4 방 지도 생성, 충돌·시야
js/actors.js       플레이어·파티 봇·적·보스·무기·전리품·성장
js/rules.js        건물 규칙 변경, 선택 사건, 결말 판정
js/draw.js         상자 조합 모델 그리기
js/hud.js          뷰파인더 HUD, 파티 창, 이름표, 피해 숫자, 채팅, 미니맵
js/input.js        키보드·마우스·터치
js/audio.js        합성 효과음 + mp3 5개
js/main.js         진행·카메라(FPS/TPS)·메뉴·결말
js/content.js      무기·스킬·규칙 수치와 짧은 문장
js/data.js         이전 판의 인물·방·사건·결말 원문 (변경 없음)
js/visitor-img.js  방문자 이미지(192px JPEG, data URI)
assets/*.mp3       이전 판에서 쓰던 음원 5개 그대로
```

## 알아 둘 것

- **실제 온라인 멀티플레이는 아닙니다.** 서버가 없는 정적 사이트라 파티원은 AI, 「월드 채팅」은 분위기용 가짜 문장입니다.
- Chrome(데스크톱·모바일 크기 에뮬레이션)에서 확인했고, Safari·Firefox 실기기와 실제 터치 기기에서는 검증하지 않았습니다.
- 음원과 방문자 이미지의 저작권·이용 조건은 이전 판 `ASSETS.md`에 적힌 원본을 따릅니다.
